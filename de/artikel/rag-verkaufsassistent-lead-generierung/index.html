Produktive Architektur

Google ADK & Cloud Run Infrastruktur im Detail

Der Agent läuft als isolierter Microservice auf Google Cloud Run im Rechenzentrum Frankfurt am Main:

  • Framework: Google Agent Development Kit (ADK) + Gemini 3.1 Flash.
  • Vektor-Engine: Vertex AI Search Data Store für Live-Sitemap-Anbindung.
  • A2A Discovery (Agent SEO): Öffentlich auffindbar über https://azhyshchev.de/.well-known/agent-card.json nach dem Linux Foundation / Google A2A Protokoll.
  • Datenschutz & DSGVO: 100 % EU-Hosting ohne feste API-Keys im Code (IAM ADC Authentifizierung).
Zukunft des B2B-Vertriebs

Agent SEO (A2A-Protokoll): Wie fremde KI-Agenten Ihre Dienstleistungen finden

Neben SEO für menschliche Besucher entsteht Agent SEO (Agent-to-Agent Discovery). Einkäufer suchen B2B-Anbieter seltener manuell – sie schicken autonome KI-Agenten los, um den Markt zu scannen.

Damit Agenten unabhängig von Frameworks (Google ADK, LangChain, AutoGen) oder Modellen (Gemini, GPT-4, Claude) kommunizieren, hat Google das A2A-Protokoll entwickelt und der Linux Foundation übergeben.

Wie A2A in der Praxis abläuft:

  • 1. Digitale Visitenkarte: Über /.well-known/agent-card.json zeigt der Server verfügbare Skills (KI Automatisierung, DATEV-Rechnungsverarbeitung, GCP-Architektur), API-Endpunkte und Sprachen.
  • 2. Indizierung: Das Manifest ist in Verzeichnissen wie dem Google Cloud Agent Registry und a2a-registry.org eingetragen.
  • 3. Autonome B2B-Anfrage: Sucht ein fremder Agent nach KI Chatbot Kundenservice oder Prozessautomatisierung KI, liest er die Visitenkarte, prüft die Daten und sendet direkt eine API-Anfrage an Cloud Run.

Ergebnis: Der Agent antwortet mit präzisen Firmendaten, qualifiziert den Lead, schreibt ihn in Cloud Firestore und schickt sofort einen Telegram-Alert an das Vertriebsteam.

Engineering Deep Dive

BANT-Qualifizierungslogik & Echtzeit-CRM-Pipeline

Strukturierte Intent-Klassifizierung statt Smalltalk: Standard-Chatbots verfangen sich in endlosen Floskeln ohne greifbaren Geschäftswert. In dieser RAG-Architektur steuert ein deterministischer State-Machine-Workflow die Konversation gezielt entlang der BANT-Kriterien (Budget, Authority, Need, Timeline). Erkundigt sich ein Website-Besucher nach Rechnungsautomatisierung, fragt der Agent proaktiv nach monatlichem Belegvolumen, eingesetzten ERP-Systemen (DATEV, Lexware, SAP) und dem gewünschten Startzeitpunkt.

Zero-Halluzination-Schutz & DSGVO-Sicherheit: Vor der Nennung von Preisen oder Integrationsdetails validiert der Agent Aussagen gegen verifizierte Unternehmensdokumente in Vertex AI Search. Preisabsprachen oder unbelegte Features werden strikt unterbunden. Sobald Kontaktdaten hinterlegt werden, validiert ein asynchroner Cloud Run Task das JSON-Payload, speichert den Lead in Google Cloud Firestore und benachrichtigt das Salesteam sofort über die Telegram Bot API mit One-Click-CRM-Übernahme.

FAQ

Häufig gestellte Fragen: RAG-Verkaufsassistenten

Wie schnell antwortet der KI-Verkaufsassistent auf Besucherfragen?
Dank der Bereitstellung als zustandsloser FastAPI-Container auf Google Cloud Run in Frankfurt am Main liegt die Antwortzeit (p95) bei unter 850 Millisekunden inklusive Vektorsuche und Token-Streaming.
Wie werden falsche Preisauskünfte oder Halluzinationen verhindert?
Das System erzwingt strikte Tool-Choice-Modi und Pydantic-Schema-Validierung. Fakten stammen ausschließlich aus verifizierten Unternehmensdokumenten, während spekulatives Erfinden von Rabatten per System-Guardrail blockiert ist.
Welche CRM- und Ticketsysteme können angebunden werden?
Qualifizierte Leads werden per REST-Webhook oder Cloud Events vollautomatisch an HubSpot, Salesforce, Pipedrive, DATEV oder interne PostgreSQL-Datenbanken übertragen.
Wie wird die DSGVO-Konformität im deutschen Markt gewährleistet?
Die gesamte Recheninfrastruktur verbleibt in der EU-Region Frankfurt (europe-west3). Kundendaten werden vor der LLM-Übertragung durch Cloud DLP-Filter anonymisiert und niemals für das Training öffentlicher Modelle verwendet.
Kann der Agent komplexe B2B-Kundenanfragen an menschliche Experten übergeben?
Ja. Sobald ein Interessent individuelle Enterprise-SLA-Verträge oder hochspezifische IT-Compliance-Anfragen stellt, triggert der Agent einen automatischen Human-Handoff. Die gesamte Konversationshistorie wird zusammengefasst an das Vertriebsteam übergeben und dem Kunden ein direkter Kalendertermin vorgeschlagen.
