Google Ads Kosten senken: Wie ein KI-Agent Ihr Konto führt, ohne Budget zu verbrennen

Ein KI-Agent kann Ihre Google Ads Kosten senken, wenn er nicht direkt am Konto hängt. Der offizielle Google Ads MCP Server liest nur; sichere Änderungen brauchen ein eigenes Backend mit Geschäftsregeln. Auf einem echten Konto sank der CPC von 0,82 EUR (Juli) auf 0,47 EUR (August bis September 2026) bei etwa 8,92 EUR pro Tag.

Ich bin Mikhail Azhyshchev, AI-Enabled Automation Engineer in München. Ich baue KI-Agenten und die Backends dahinter für Unternehmen im DACH-Raum. Dieser Artikel zeigt ohne Fachchinesisch, wie das aussieht und was dabei herauskam.

Ausgangslage

Was Unternehmen von Google Ads Automatisierung wirklich wollen

Wer nach Google Ads Betreuung oder einer Google Ads Agentur sucht, hat selten ein technisches Problem. Meist ist es dasselbe Muster: Das Konto läuft, das Budget fließt, und niemand kann sagen, wohin genau. Die Rechnung kommt jeden Monat, die Erklärung nicht.

Was Inhaber und Marketingleiter in Gesprächen tatsächlich verlangen, lässt sich auf vier Wünsche reduzieren:

  • Weniger Klicks von Menschen, die etwas ganz anderes suchen als Ihr Angebot.
  • Ein Bericht in normaler Sprache statt einer Tabellenwüste.
  • Klare Grenzen: Der Klickpreis darf nicht unbemerkt steigen.
  • Nachvollziehbarkeit: Was wurde wann geändert, und warum?

Genau diese Alltagsarbeit kann ein KI-Agent übernehmen: Berichte lesen, verschwendetes Budget finden, Gebotsobergrenzen anpassen, negative Keywords (Ausschlussbegriffe) ergänzen. Wer schon einmal versucht hat, AdWords zu optimieren, kennt diese Liste. Sie ist lang, sie wiederholt sich, und sie bleibt gern liegen. Das passt gut zu einem Agenten, mit einer Bedingung: Er darf nicht ohne Leitplanken arbeiten.

Das Risiko

Warum man einen KI-Agenten nicht direkt an Google Ads anschließt

Der naheliegende Weg: den Agenten direkt mit der Google Ads API oder einem fertigen MCP Server verbinden. Das klingt bequem und ist genau der Punkt, an dem Konten Schaden nehmen. Die API führt aus, was man ihr schickt. Ob eine Änderung für Ihr Geschäft sinnvoll ist, prüft sie nicht.

Das sagt die Dokumentation von Google selbst (geprüft am 13.10.2026):

  • Der offizielle Google Ads MCP Server ist in der aktuellen Version rein lesend. Er bietet drei Werkzeuge: list_accessible_customers, search (GAQL-Abfragen) und get_resource_metadata. Laut Dokumentation kann er keine Gebote ändern, keine Kampagnen pausieren und keine neuen Assets anlegen.
  • Um etwas zu ändern, braucht ein Agent Schreibzugriff (Mutate) auf die Google Ads API selbst.
  • Die API kennt keine Objektsperren. Gleichzeitige Änderungen am selben Objekt führen zum Fehler CONCURRENT_MODIFICATION_ERROR.
  • Für sichere Änderungen empfiehlt Google Testkonten, wo möglich nur lesende Anfragen, validate_only bei Änderungsanfragen und die Prüfung des Änderungsverlaufs (Change History).

Das Ergebnis: Der Server liest, die API schreibt, und dazwischen steht nichts, was Ihre Geschäftsregeln kennt. Wie hoch darf ein Gebot werden? Wie schnell darf es sich ändern? Welche Suchbegriffe wollen Sie nie bezahlen? Wer muss bestätigen? Diese Regeln existieren nur, wenn sie jemand baut. Ein Agent, der sie nicht kennt, kann sie nicht einhalten, so gut das Modell auch ist.

Die Lösung

So sieht ein sicheres Setup aus: eigenes Backend mit Geschäftsregeln

Mein Ansatz: Der Agent spricht nie mit der Google Ads API, sondern nur mit meinem Backend. Das ist ein eigener MCP Server in Python mit Geschäftslogik. Er stellt dem Agenten 36 Werkzeuge bereit: Berichte, Suche in den Suchbegriffen, negative Keywords, Schritte für Gebotsobergrenzen, Anzeigenrotation, Änderungsverlauf und Beobachtbarkeit. Jede Regel steckt im Code, nicht in einer Bitte an das Modell. Fünf davon sind für Sie als Inhaber entscheidend:

1. Erst der Gesundheitscheck, dann die Arbeit Vor jedem Anzeigenwerkzeug prüft das Backend den Zustand der Werkzeuge, Änderungen außerhalb des Agenten und den Prozessstatus. Bis dahin antwortet jedes Werkzeug mit PREFLIGHT_REQUIRED. Steht der Status auf ATTENTION, muss der Inhaber bestätigen, bevor es weitergeht. Im Journal stehen dafür im Oktober 3 Abweisungen.
2. Harte Grenzen für Gebote Die Gebotsobergrenze liegt im Code zwischen 0,10 und 3,00 EUR und bewegt sich nur in Schritten von 0,05 EUR. Am 05.10.2026 lehnte die Prüfschicht eine fehlerhafte Änderung der Obergrenze ab. Es wurde nichts geändert.
3. Nur ändern, was benannt ist Jede Änderung sendet eine ausdrückliche Update-Maske. Es ändert sich ausschließlich das genannte Feld, nichts nebenbei.
4. Suchbegriffe, die Sie nie wollen Negativlisten pro Land (DE, FR, ES) und eine automatische Erkennung von Keywords, die sich zwischen Kampagnen gegenseitig Konkurrenz machen.
5. Ein Protokoll für jeden Aufruf Zeitstempel, Werkzeug, Lesen oder Änderung, Ergebnis, Laufzeit und Trace-ID werden festgehalten. Vom 01.10. bis 13.10.2026 waren es 237 Einträge: 216 Lesezugriffe und 21 Änderungen.

FastMCP-Evolution: Neu in Version 1.1.0 (November 2026)

Das System ist von einem internen Prototyp zu einem Open-Source-Enterprise-Framework herangewachsen – erweitert auf 59 spezialisierte Werkzeuge und abgesichert durch 237 Offline-Tests.

  • 59 Werkzeuge (+23 neu): Tiefgreifendes Lifecycle-Management für Anzeigengruppen, Bild-Assets, Geo-Targeting, Conversion-Ziele und Suchbegriff-Mining.
  • Google Shopping & Merchant Center Integration: Automatische Überprüfung des Feed-Status (check_shopping_readiness) über Merchant-Center-IDs hinweg. Jede neue Shopping-Kampagne wird per Design im Status PAUSED angelegt.
  • Geschäftsregeln als Daten (Policy as Data): Alle Unternehmensregeln (Konto-IDs, verbotene Suchbegriffe, erlaubte Domains, Gutschein-Parameter) liegen in einer separaten config/policy.local.json. Der Code selbst ist 100% neutral und lecksicher.
  • Harte Invarianten im Code: Der Agent kann unmöglich Ihr letztes Zielland löschen, keine leeren Anzeigengruppen aktivieren und verschiebt CPC-Obergrenzen streng um maximal ±0,05 EUR.
  • W3C Distributed Tracing: Lückenlose Nachvollziehbarkeit: Erfassung von Google Request-IDs und getrennte Messung lokaler Python-Prüfung vs. Google gRPC-Laufzeit.
  • 237 Offline-Tests: Die komplette Testsuite läuft in 2,2 Sekunden durch – ohne einen Cent für Live-APIs zu verbrauchen.

Kosten

Google Ads Kosten: Klicks am unteren Marktende statt Gebotskrieg

Das Konto gehört zu einem E-Commerce-Shop für Wohn- und Kinderdekoration, mit Kampagnen in Deutschland, Österreich, Spanien und Frankreich. Das Budget ist klein: 276,66 EUR in 31 Tagen, also etwa 8,92 EUR pro Tag für alle vier Länder zusammen (18.08. bis 17.09.2026).

Der Klickpreis in drei Messpunkten

  • 0,82 EUR im Schnitt (120,03 EUR bei 147 Klicks), 05.07. bis 04.08.2026, vor der Bereinigung, 2 Kampagnen.
  • 0,53 EUR im Schnitt, 21.07. bis 04.08.2026, dieselben 2 Kampagnen nach Beginn der Bereinigung.
  • 0,47 EUR im Schnitt über alle 6 Kampagnen mit Ausgaben (276,66 EUR bei 592 Klicks), 18.08. bis 17.09.2026. Je Kampagne lag der Wert zwischen 0,45 und 0,55 EUR.

Die Gebotsstrategie ist einfach: Klicks maximieren (Maximize clicks) mit einer Obergrenze für den Klickpreis pro Kampagne. Der Agent verschiebt diese Obergrenze nur in den festen Schritten, die das Backend erlaubt.

Google Werbung Kosten: Warum ich nicht um Platz eins biete

Im September lag der Anzeigenanteil (Impression Share) bei 10 bis 20 Prozent. 63 bis 80 Prozent gingen wegen des Anzeigenrangs verloren (18.08. bis 17.09.2026). Das ist ein bewusster Kompromiss. Der Plan lautete: lieber 10 Prozent Anzeigenanteil bei einem Klickpreis im Rahmen als ein Höchstgebot für die Spitzenposition.

Das Audit zeigte außerdem, dass eine höhere Obergrenze ohne bessere Landingpages nur Geld verbrennen würde. Wir bezahlen also nicht für Toppositionen. Der niedrige Anzeigenrang verrät zugleich, wo die Landingpages Arbeit brauchen.

Auswertung

Google Ads plus GA4: sehen, was der Traffic macht

Ein niedriger Klickpreis sagt nichts über die Qualität der Besucher. Deshalb ist Google Ads mit GA4 verbunden. Von 05.07. bis 04.08.2026 kamen 235 Sitzungen aus google/cpc, 72 Prozent davon engaged, die durchschnittliche Dauer lag bei 1m30s.

AdWords optimieren heißt: Suchbegriffe lesen

Ich habe 909 echte Suchanfragen aus 30 Tagen (Mitte Juli bis 15.08.2026) durchgesehen. Daraus entstand ein Schutzschild aus 21 negativen Begriffen für die Kampagnen in Deutschland und Österreich.

Das Leck: Wandtattoo und Wandsticker

Am 04.08.2026 fiel auf: Suchen nach Wandtattoo und Wandsticker, also einem anderen Produkt als Tapeten, kosteten 22,07 EUR. Das waren 11 Klicks und 0 Verkäufe, zusammen 18,4 Prozent der Ausgaben der letzten 30 Tage. Die Anzeigengruppe wurde noch am selben Tag pausiert.

Doppelte und zu breite Keywords

Am 04.08.2026 wurden außerdem 36 doppelte Keywords pausiert, die sich gegenseitig Konkurrenz machten. Drei breite Keywords, die in 30 Tagen 44,85 EUR gekostet hatten, wurden ebenfalls pausiert. Keine dieser Maßnahmen ist spektakulär. Zusammen räumen sie ein Konto auf.

Für wen das passt

KI-Agent statt Google Ads Agentur? Für wen das passt

Die ehrliche Antwort: nicht für jeden. Der Ansatz passt zu kleinen und mittleren Unternehmen im DACH-Raum, die mit 5 bis 50 EUR pro Tag werben und für diese Summe keine laufende Agenturbetreuung wollen oder brauchen. Dort lohnt sich ein Agent, der die wiederkehrende Arbeit zuverlässig erledigt und jede Änderung protokolliert.

Eine Google Ads Agentur bleibt sinnvoll, wenn Sie Strategie, Kreation und Beratung als Paket einkaufen möchten. Das ersetzt der Agent nicht. Er ersetzt die mechanische Arbeit: Berichte, Suchbegriffe, Duplikate, Gebotsobergrenzen.

Nicht passend ist der Ansatz, wenn Angebot oder Landingpage nicht stimmen. Dann macht Automatisierung nur schneller sichtbar, was ohnehin nicht funktioniert. Das Audit auf diesem Konto hat genau das gezeigt.

FAQ

Häufige Fragen zu Google Ads Kosten und KI-Agenten

Was kostet Google Ads pro Monat mit kleinem Budget?
Die Google Ads Kosten pro Monat folgen Ihrem Tagesbudget und dem Klickpreis, eine feste Gebühr gibt es dafür nicht. Mein Praxisbeispiel: 276,66 EUR in 31 Tagen, etwa 8,92 EUR pro Tag, verteilt auf 4 Länder, bei durchschnittlich 0,47 EUR pro Klick (18.08. bis 17.09.2026). Das ist ein einzelner Fall und keine Preisliste. Rechnen Sie mit Ihrem eigenen Tagesbudget.
Kann ein KI-Agent mein Google Ads Konto selbst verwalten?
Ja, die tägliche Routine kann er übernehmen: Berichte lesen, Verschwendung in den Suchbegriffen finden, Gebotsobergrenzen anpassen und negative Keywords ergänzen. Bedingung sind Leitplanken. In meinem Setup spricht der Agent nur mit einem eigenen Backend, das Grenzen und Prüfungen erzwingt. Vom 01.10. bis 13.10.2026 gab es 237 Einträge im Protokoll, davon 21 Änderungen. Strategie und Angebot bleiben Ihre Entscheidung.
Reicht der offizielle Google Ads MCP Server?
Zum Lesen ja, zum Verwalten nein. Laut Google Dokumentation ist er in der aktuellen Version strikt lesend und kann keine Gebote ändern, keine Kampagnen pausieren und keine neuen Assets anlegen. Für Änderungen braucht ein Agent Schreibzugriff auf die Google Ads API selbst, und dort fehlen Ihre Geschäftsregeln. Die gehören in ein eigenes Backend.
Wie verhindere ich, dass ein KI-Agent zu viel ausgibt?
Mit harten Grenzen im Code, nicht mit Bitten an das Modell. Bei mir liegt die Gebotsobergrenze zwischen 0,10 und 3,00 EUR und bewegt sich nur in Schritten von 0,05 EUR. Am 05.10.2026 lehnte die Prüfschicht eine fehlerhafte Änderung ab, es wurde nichts geändert. Dazu kommen ein Gesundheitscheck vor jeder Arbeit und ein Protokoll aller Aufrufe.
Brauche ich dann noch eine Google Ads Agentur?
Das hängt davon ab, was Sie von ihr erwarten. Der Agent erledigt Routine: Berichte, Suchbegriffe, Duplikate, Gebotsobergrenzen. Strategie, Angebot und Landingpages ersetzt er nicht. Bei sehr kleinen Budgets kann ein eigener Agent mit Backend eine Alternative zur laufenden Agenturbetreuung sein. Ob es sich für Sie lohnt, klären wir im 30-Minuten-Gespräch.
Woher weiß ich, ob der Traffic aus Google Ads etwas bringt?
Über die Verbindung von Google Ads mit GA4. In meinem Beispiel kamen 235 Sitzungen aus google/cpc (05.07. bis 04.08.2026), 72 Prozent davon engaged, im Schnitt 1m30s. Die Verkäufe laufen über einen externen Checkout ohne direkte serverseitige Google-Ads-Attribution. Gemessen werden Klickpreis, entfernte Verschwendung und das Verhalten des Traffics.
