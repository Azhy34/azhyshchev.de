AI-Managed Ad Account

A live e-commerce ad account across Google Ads and Pinterest, operated day to day by an AI agent instead of by clicking through dashboards. The agent does not talk to the advertising APIs directly. It works through two custom tool servers that encode the account's business rules, so budget protection, creative standards and approval gates are enforced by the tooling rather than by remembering to check.

The problem this solves

The first version of this automation used a standard off-the-shelf connector to the Google Ads API. It reported the account as perfect, 100 out of 100, while a manual review found ads below the quality standard, keywords competing against each other, and one broad match term that had spent 30.02 EUR on 18 clicks. The automation was checking whether the API accepted each change. It had no idea whether the money was well spent.

What it does

Capabilities

  • Mines real search queries on a schedule, classifies them into winners and waste, and applies negative keywords before the next spend cycle.
  • Detects keywords duplicated across your own campaigns so they stop competing in the same auction and inflating your cost per click.
  • Validates every ad against a quality checklist before it can go live, including full asset coverage in the target language.
  • Pulls performance and spend from both channels into one reporting surface with a shared keyword bank.
Safety model

Why it is safe to run on a live budget

  • Every change that costs money is created in a paused state and waits for an explicit human go.
  • Bid mutations always carry an explicit field mask, which blocks a known platform behaviour that silently resets bids to 0.01 EUR.
  • Ads below the creative standard are rejected at the tool boundary rather than published and flagged later.
  • Every decision, test and adjustment is written to a dated log, so the account has an audit trail rather than a black box.
Fit

Who this is built for

  • E-commerce and B2B companies with consistent monthly paid search spend, where wasted percentage points are real money.
  • Advertisers running more than one channel who currently compare performance by exporting spreadsheets.
  • Companies without an in-house PPC engineer, where the account is managed part time or handed off with limited visibility.
  • Teams adopting AI that want operational guardrails in place before an agent touches a live budget.
Engineering

How it is built

  • Two local MCP servers in Python: 18 tools over Google Ads API v23, 9 tools over Pinterest Ads API v5.
  • The tool surface mirrors the advertising hierarchy, campaign then ad group then ad, not the API endpoint list.
  • Business rules live inside the tools, so invalid states are unreachable rather than merely discouraged in a prompt.
  • The agent passes identifiers and copy. The server assembles the platform payloads, which keeps each operation cheap and fast.
